# Code of Conduct

## Our Pledge

We want Smart Civic Connect to be a welcoming project for learning, civic technology, and collaboration. Everyone who participates is expected to act with respect, patience, and care.

## Expected Behavior

- Be respectful of different backgrounds, skill levels, and viewpoints.
- Give constructive feedback focused on the work.
- Ask questions in good faith.
- Help keep discussions useful, safe, and on topic.
- Be careful with civic data, personal information, photos, and location details.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language
- Sharing private information without permission
- Posting real citizen data in demos, issues, commits, or screenshots
- Deliberately disrupting project work or community spaces
- Dismissing security or privacy concerns without review

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributions that violate this code of conduct. Repeated or serious violations may lead to restricted participation in the project.

## Reporting

If you see behavior that violates this code of conduct, contact the repository owner or maintainer privately. Include relevant context, links, screenshots, or logs when appropriate.

## Scope

This code applies to project spaces, including repository discussions, issues, pull requests, demos, documentation, and related communication channels.
